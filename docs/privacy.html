中文

dsh-google-sheets 是运行在用户自己电脑上的开源插件。经用户授权后，它使用 Google 表格接口（spreadsheets）读写用户指定的表格，并使用 Drive 只读权限（drive.readonly）按名字查找表格、在线读取用户指定的 Google 文档；不修改、不删除 Drive 上的任何文件。

  • 授权令牌只保存在用户电脑的 ~/.dsh-gsheets/ 目录，不上传到任何服务器。
  • 表格数据只在用户电脑与 Google 之间传输；插件作者不收集、不存储、不分享任何用户数据。
  • 插件读取到的数据会交给用户自己配置的 AI 模型处理，这一部分受用户所选模型服务商的隐私政策约束。
  • 用户可随时在 Google 账号权限页 撤销授权，并删除 ~/.dsh-gsheets/ 目录。

本插件对 Google 用户数据的使用遵守 Google API 服务用户数据政策，包括其中的有限使用要求。

English

dsh-google-sheets is an open-source plugin that runs on the user's own computer. With the user's consent it uses the Google Sheets API (spreadsheets scope) to read and write spreadsheets the user specifies, and Drive read-only access (drive.readonly) to find spreadsheets by name and read Google Docs the user points to; it never changes or deletes anything on Drive.

  • OAuth tokens are stored only on the user's computer in ~/.dsh-gsheets/ and are never uploaded.
  • Spreadsheet data travels only between the user's computer and Google. The author collects, stores and shares no user data.
  • Data the plugin reads is passed to the AI model the user has configured, under that provider's privacy policy.
  • Users can revoke access at any time at Google Account permissions and delete ~/.dsh-gsheets/.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
