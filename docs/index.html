dsh-google-sheets

DeepSeek Harness（DSH）插件：直接调用 Google 表格官方接口找表、读（含批注和颜色）、写、追加、新建；每次写入后自动回读核对。

A DeepSeek Harness plugin that reads and writes Google Sheets through the official API, verifying every write by reading it back.
